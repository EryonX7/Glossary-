# IT Glossary — Future Glass

Адаптивный интерактивный сайт на HTML, CSS и JavaScript, созданный на основе предоставленного Word-глоссария.

## Запуск
Откройте `index.html` в браузере. Для GitHub Pages загрузите `index.html` и `data.js` в корень репозитория, затем Settings → Pages → Deploy from a branch → main / root.

## Возможности
Поиск, категории, алфавитная навигация, избранное (localStorage), всплывающие карточки, викторина, мобильная адаптация.

Определения берутся из предоставленного документа. Пустые определения помечаются явно. Категории назначены автоматически для удобства навигации и не являются частью исходного документа.
